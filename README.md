# Splatoon3 ランダム二つ名

[![check](https://github.com/YutaGoto/splatoon3-shellout-titles/actions/workflows/check.yml/badge.svg)](https://github.com/YutaGoto/splatoon3-shellout-titles/actions/workflows/check.yml)

React + Vite + Tailwind CSS で構築された Splatoon3 ランダム二つ名検索アプリです。

### Usage

Node.js (v20+) と pnpm を用意して、依存関係をインストールします:

```sh
pnpm install
```

開発サーバーを起動します:

```sh
pnpm dev
```

本番ビルドとプレビュー:

```sh
pnpm build
pnpm preview
```
